# MindMapr – Smart Revision Assistant

## Description

MindMapr is a smart revision assistant designed to help students organize
their study topics, subtopics, and notes in a structured format.

The application uses Flask for the backend and HTML, CSS, and JavaScript
for the frontend. Study data is stored in a JSON file.

## Features

- Add study topics
- Add subtopics and notes
- View stored topics
- Delete topics
- Delete subtopics
- Store data using JSON
- Simple and user-friendly web interface

## Technologies Used

- Python
- Flask
- Flask-CORS
- HTML
- CSS
- JavaScript
- JSON
